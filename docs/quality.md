# 质量门槛（收录判据）

> 「质量差的不要收入」的可执行版本。`tools/validate.py` 逐字强制，任一不满足即构建失败。
> 这是「收录最完整」的对立面——再完整也不能收质量不达标的字条。

`validate.py` 十项校验（对应 `PLAN.md` §2.3 / §2.4）：

1. **唯一今字**——今字解读明确、无歧义；歧义/多解剔除或登记 `data/known-defects.json`。
2. **解析完备**——每字必须有「解析」段（甲骨形 → 部件 → 今字的推演链），不能只给今字。
3. **来源可溯**——`source` 必填，无来源孤字不收。
4. **无重复**——今字全库唯一（同字不同解须登记，否则拒收）。
5. **无低质内容**——低俗、歧义、政治敏感、无法核实的「民间字源」一律拒收（`check-legal.mjs` 与人工审核共同把关）。
6. **难度评级**——`difficulty` 必填且在 1–5。
7. **公版安全**——甲骨卜辞本身（商代）= 公版；现代释义须署名且卒年 ≤ 当前年 − 50，或来源确证/已授权，否则进 `pending/`。
8. **字类合法**——`type` 必须取自合法集（自然现象 / 动植物 / 人体动作 / 器物 / 数目 / 抽象）。
9. **图形完备**——`glyph` 路径存在、非空、哈希入 `data/checksums.json`（图也是唯一事实源的一部分）。
10. **单字约束**——`char` 必须单字（`char_len=1`），多字词不进字库（可进 `pending/` 登记）。

## 解析段的标准

「解析」段必须给出**甲骨形 → 部件 → 今字**的推演链，说清：

- 甲骨形**长什么样**（圆形 / 月牙 / 三峰 / 侧立人…），
- 每个部件**指代什么**（中心点指日之中心、两角指牛角…），
- 这个象形**怎么演变**成今字（圆变方、笔画规范…）。

只写「这是太阳，所以是日」这种没有推演链的，不算解析完备。

## 难度评级的标准

- **1 星**：甲骨形与今字直观对应，一眼可认（日、月、山、人）。
- **2 星**：甲骨形与今字有明显演变，需要一点字源知识（水、火、牛、木、目）。
- **3 星**：甲骨形与今字差异大，需要认真看部件（马、竹、手）。
- **4–5 星**：M2 起收录的会意字、假借字、字形歧义大的字。

难度用于分站游戏的难度轴与玩法匹配，评级必须与「猜这个字有多难」一致，
不能凭手感乱标。
